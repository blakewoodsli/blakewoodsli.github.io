一个基于 Go 语言的 Web 服务，实现了用户管理、每日签到、积分累积与权益兑换的全流程。旨在通过游戏化运营提升用户活跃度与留存。

#### 技术栈

Go, Gin, Gorm, MySQL, Redis, JWT, Docker, Zap

#### 主要职责与项目成果

- 从零设计并完成基于 Gin 与 Gorm 的 MVC 架构，涵盖需求分析、数据库设计至核心功能开发。
- 设计并实现 Redis + MySQL 二级缓存与存储方案，缓存用户积分、签到状态等热点数据，显著提升接口响应速度与系统并发能力；采用Redis Bitmap 存储近期签到数据，实现连续天数统计；历史数据按月归档至 MySQL，兼顾实时性能与存储成本。

- 通过 Dockerfile 与 Makefile 定义容器化构建流程，实现从代码编译、镜像打包到推送到仓库的一键化发布，提升部署效率与一致性。
- 设计并实现积分兑换体系，支持虚拟道具与实物礼品的差异化兑换流程；运用 MySQL 事务与 Redis 分布式锁，确保积分扣减与资源发放的原子性，保障数据强一致性与业务准确性。
